# Política de Privacidad

Esta Política de Privacidad explica cómo el bot Predator maneja, almacena y protege los datos relacionados con su funcionamiento.

## Información que recopilamos
El bot puede almacenar información necesaria para su operación, incluyendo:
- IDs de usuarios, servidores y roles
- Preferencias relacionadas con configuraciones del bot
- Datos de actividad del usuario (por ejemplo, estadísticas de tiempo o uso de comandos)

No recopilamos datos sensibles ni información personal más allá de lo estrictamente necesario para que el bot funcione.

## Cómo utilizamos la información
La información almacenada se utiliza exclusivamente para:
- Proporcionar las funciones principales del bot
- Mejorar la estabilidad y experiencia del usuario
- Mantener configuraciones específicas del servidor

## Compartición de datos
No compartimos, vendemos ni transferimos datos a terceros.  
Los datos únicamente se usan dentro del bot Predator.

## Eliminación de datos
Los administradores pueden solicitar la eliminación de datos relacionados con su servidor contactando al desarrollador del bot.

## Seguridad
Se toman medidas razonables para proteger los datos del acceso no autorizado.

## Contacto
Si tienes preguntas sobre esta política, puedes contactarme a través de Discord.
