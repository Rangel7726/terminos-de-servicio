# Términos del Servicio

Estos Términos del Servicio aplican al uso del bot Predator y cualquier funcionalidad asociada.

## Uso del bot
- El bot no debe utilizarse para actividades maliciosas, ilegales o que violen los Términos de Servicio de Discord.
- El bot no debe utilizarse para dañar servidores o usuarios.

## Recopilación de datos
El bot puede almacenar información necesaria para su funcionamiento, como IDs, roles o estadísticas de actividad.  
No se comparte información con terceros.

## Responsabilidad
El desarrollador no se hace responsable del mal uso del bot por parte de administradores o usuarios.

## Contacto
Si tienes dudas, puedes comunicarte conmigo vía Discord.
